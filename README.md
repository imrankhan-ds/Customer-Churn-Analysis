# Customer Churn Analysis

## Project Overview

This project analyzes customer churn using Python to identify patterns and factors associated with customers leaving a service.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Dataset

The dataset contains customer information such as:

- Customer demographics
- Contract type
- Internet service
- Payment method
- Tenure
- Monthly charges
- Total charges
- Churn status

## Data Analysis

The project includes:

- Data exploration
- Data cleaning
- Missing/invalid value handling
- Churn distribution analysis
- Categorical data analysis
- Tenure analysis
- Monthly and total charges analysis
- Correlation analysis
- Correlation heatmap
- Data visualization

## Key Analysis

The project analyzes the relationship between customer churn and factors such as:

- Contract type
- Internet service
- Payment method
- Online security
- Tech support
- Tenure
- Monthly charges
- Total charges

## Project Workflow

1. Load the dataset
2. Explore the data
3. Check data types and missing values
4. Analyze customer churn
5. Clean the dataset
6. Perform exploratory data analysis
7. Create visualizations
8. Analyze correlations
9. Identify business insights

## Key Findings

- Approximately 26.5% of customers in the original dataset had churned.
- Customer tenure showed a relationship with churn behavior.
- Contract type and service-related factors showed differences in churn patterns.
- Monthly and total charges were analyzed across churn groups.
- Numerical relationships were examined using a correlation heatmap.

## Project Status

Completed as a Data Analysis and Exploratory Data Analysis (EDA) project.
